# 🌙 Pochiiii's Safe Place

A cute, cozy, interactive friendship surprise website.

## Replace your photos

Put your photos in:

`assets/photos/`

Use these exact names:

- photo-01.jpg
- photo-02.jpg
- photo-03.jpg
- photo-04.jpg
- photo-05.jpg
- photo-06.jpg

If you have PNG/WebP files, either rename them to `.jpg` only if they really are JPEGs, or change the filenames in `index.html` and `script.js`.

## Add the 8 voice recordings

Put your recordings in:

`assets/audio/`

Use these exact names:

1. `open-when-crying.mp3`
2. `open-when-hug.mp3`
3. `open-when-sleep.mp3`
4. `open-when-overthinking.mp3`
5. `open-when-laugh.mp3`
6. `open-when-alone.mp3`
7. `open-when-motivation.mp3`
8. `open-when-miss-us.mp3`

Recordings can be 1–3 minutes each. MP3 is recommended for smaller file sizes.

## Customize

Most visible text is in `index.html` and `script.js`.

## Deploy on Vercel

1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Go to Vercel and import the GitHub repository.
4. Framework preset: **Other** (or leave auto-detected).
5. Build command: leave empty.
6. Output directory: leave empty / root.
7. Deploy.

This is a static website: no database, API key, or backend is required.
